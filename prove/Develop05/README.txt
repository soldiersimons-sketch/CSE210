CSE 210 - Unit 05 Eternal Quest

Copy Program.cs, Goal.cs, SimpleGoal.cs, EternalGoal.cs, ChecklistGoal.cs,
and GoalManager.cs into your course repository's Prove/Develop05 folder.

Do not delete your existing Develop05.csproj file. If it is the standard
CSE 210 course project, it automatically includes the new .cs files.

In a terminal inside Prove/Develop05, run:
  dotnet run

Test:
1. Create a Simple Goal and record it twice: receive points only once.
2. Create an Eternal Goal and record it twice: receive points both times.
3. Create a Checklist Goal with target 2 and bonus 100; record twice:
   get regular points each time, plus bonus on the second time.
4. Save to goals.txt, exit, re-run, and load goals.txt.
5. Earn 1,000+ points to see your level increase.

Then commit and push your work to GitHub and submit the repository URL in I-Learn.
